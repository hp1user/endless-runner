   - Current (Tuned) Settings:

3. TOUCH CONTROLS & WEAPON WHEEL
--------------------------------------------------------------------------------

A. TouchManager.cs (Component on "GameManger" GameObject)
   - Previous Settings:
       requireTouchOnBottomHalf: true (hard-rejected any taps on torso/head above 50% screen)
       holdTimeToOpenWheel:      0.50f
       detection method:         Single point raycast against collider only
   - Current (Fixed) Settings:
       requireTouchOnBottomHalf: false (allows tapping anywhere on character body)
       holdTimeToOpenWheel:      0.35f (more responsive long-press hold)
       detection method:         3-tier detection:
                                 1. Raycast with QueryTriggerInteraction.Collide
                                 2. 0.45m SphereCastAll (forgiving around limbs/edges)
                                 3. Screen-space proximity fallback to character bounds
                                 + 0.25s press grace window

B. WeaponWheelToolkitManager.cs / UIToolkit GameObject
   - Previous State:
       "UIToolkit" GameObject in scene was INACTIVE (m_IsActive: 0).
       Because the GameObject was disabled, Awake() never ran and
       WeaponWheelToolkitManager.Instance was NULL, throwing NullReferenceException
       in TouchManager.Update() line 98 whenever a touch hold was completed.
   - Current (Fixed) State:
       "UIToolkit" GameObject is ACTIVE (m_IsActive: 1).
       WeaponWheelToolkitManager.Instance property now includes auto-recovery
       to automatically find and activate itself even if accidentally disabled.
       EnsureInitialized() added to safely build UI Toolkit visual elements.

C. UIManager.cs / HUD Graphic Raycasts
   - Previous State:
       67 UI graphics under Canvas/UIManager had raycastTarget = true,
       intercepting touches and clicks across the screen.
   - Current (Fixed) State:
       UIManager.MakeHUDClickThrough() automatically disables raycastTarget on
       all decorative HUD cards, fills, tracks, and text, leaving only
       interactive buttons enabled (2 targets remaining).

D. Man_Rig GameObject Tag
   - Previous: Untagged
   - Current:  "Player"

HOW TO REVERT TOUCH & WHEEL:
   - On "GameManger" -> TouchManager component in Inspector:
       Set "Require Touch On Bottom Half" = true
       Set "Hold Time To Open Wheel" = 0.5
